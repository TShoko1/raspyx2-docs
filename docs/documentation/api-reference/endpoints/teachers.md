# Преподаватели (Teachers)

Управление преподавателями.

## Эндпоинты

| Метод | Путь | Описание |
|-------|------|-----------|
| `POST` | `/api/v1/teachers` | Создание нового преподавателя |
| `GET` | `/api/v1/teachers/` | Получение списка преподавателей |
| `GET` | `/api/v1/teachers/fullname/{fullname}` | Получение преподавателя по ФИО |
| `GET` | `/api/v1/teachers/uuid/{uuid}` | Получение преподавателя по UUID |
| `PUT` | `/api/v1/teachers/{uuid}` | Обновление преподавателя |
| `DELETE` | `/api/v1/teachers/{uuid}` | Удаление преподавателя |
