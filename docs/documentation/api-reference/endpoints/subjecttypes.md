# Типы предметов (Subject Types)

Управление типами учебных предметов (лекция, практика, лабораторная и т.д.).

## Эндпоинты

| Метод | Путь | Описание |
|-------|------|-----------|
| `POST` | `/api/v1/subjecttypes` | Создание нового типа предмета |
| `GET` | `/api/v1/subjecttypes/` | Получение списка типов предметов |
| `GET` | `/api/v1/subjecttypes/type/{type}` | Получение типа предмета по названию |
| `GET` | `/api/v1/subjecttypes/uuid/{uuid}` | Получение типа предмета по UUID |
| `PUT` | `/api/v1/subjecttypes/{uuid}` | Обновление типа предмета |
| `DELETE` | `/api/v1/subjecttypes/{uuid}` | Удаление типа предмета |
